# P05 剩余验收清单

截至 2026-10-01，发布基线为 `23a8250`。P05 仍有 **3 个未关闭验收组**；组内不是已穷尽的缺陷清单，不据此计算完成率。历史切片证据保留在 [实施记录](implementation_status.md)，本清单只表达当前剩余范围。

## 1. 剩余展示业务接口与通用校准

本轮完成第一段源码边界审计，未修改运行时，也未关闭本组。真实入口为宿主 `project.godot` → 插件 `showcase/wardrobe.tscn` → `wardrobe.gd`；作者配置由场景和 character definition 输入。

### 已确认需要收口的接口

| 项目 | 当前调用与责任边界 | 下一切片及关闭条件 |
| --- | --- | --- |
| 漫画生成几何查询 | `showcase/wardrobe_framework.gd::_pin_spawn(token)` 读取 `comics._effects.back().mesh`；`runtime/npr_comic_layer.gd::play()` 返回 token，但调用者仍依赖内部数组末项及可变 MeshInstance3D | 优先提供按 token 查询的只读几何快照，不暴露整个内部 effect；保留既有 3×3 整卡采样和 pin 算法。覆盖未知、取消、替换、过期 token、多效果并存及快照隔离；重跑漫画生成固定/背面隐藏和真实头发遮挡图像门禁 |
| 表情立即求值 | `wardrobe.gd`、`wardrobe_visual_layers.gd` 和 `wardrobe_framework.gd` 调用 `runtime/animation/npr_performance.gd::_apply_face()` | 定义明确的公开立即求值入口，保持 delta、最新用户输入、眨眼/口型所有权与 expression_evaluated 信号顺序；不能直接改为推进整个动作时钟。覆盖暂停下调整、取消临时表情、恢复和工作台专项 |
| 暂停状态读取 | `wardrobe_framework.gd::set_locked()` 读取 `performance._paused`，但写入已有 `set_paused()`；雨水 `_paused` 属于同一展示层 | 优先收口跨 runtime 的动作暂停查询；区别用户暂停、隐藏中性化、工作台观察锁定。保持原暂停精确恢复，复跑工作台、实时与隐藏生命周期专项；雨水展示内部接口单独评估，不混同运行时泄漏 |
| 诊断符号节点 | 工作台读 `visual_layers._symbol_eyes/_symbol_mouth`，后者转发 `runtime/face/npr_face_rig.gd` 的公开节点 | 评估展示层提供语义化诊断目标集合；此处首先是展示模块内部耦合，不应据此宣称 face rig 尚未提取。验证诊断退出、符号眼嘴独立切换与 actor 重建 |

以上是本次范围内确认的 **4 项接口候选工作**，不是全项目只剩 4 项缺陷。其中漫画按 token 的只读几何查询作为下一实现切片；其余按跨运行时边界优先级处理。

### 不应机械改写的内容

- panel 与 host 的 `_content`、构建回调等是同一展示实现的内部协作；不能仅凭下划线将所有引用改成公开框架 API。
- `comic_profile` 已提供卡片偏移、尺寸、锚点与脸部校准，角色几何查询已走 `intersect_role_ray()`；这些已完成工作不再重复列为提取任务。
- `_pin_spawn()` 中 `0.85 * scale`、`0.04 * scale`、`0.20 * scale` 是当前范围筛选和深度偏置策略。尚未证明其适用全部标准角色，也未证明必须全部变成作者参数；保留算法并针对尺度、视角、锚点范围另做校准判定。
- 场景显式选择银狼 definition、角色 ID 与演示音频是样例作者输入，不是运行时固定样例路径缺陷。
- BH/BJ/BK/BM/BN 的镜头、配色、袜口工厂默认已完成，不重复计数；此轮没有逐项重新运行其旧证据。

本组最终关闭还需补齐其余模块的业务输入、坐标/掩码/骨骼合同审计，以及配置、制作说明、程序检查和外部 AI 用例的一致性。当前审计不是全库完结证明。

## 2. 实时动态、生命周期与时序视觉

- BT 的严格图像恢复/no-op 一级漂移仍未定位；失败现场 sampler A/B/A 分支尚未触发，不得把近期绿色对照算作修复。保留原断言、历史失败及低介入 hook，不追加同类独立随机搜索。
- 仍须补齐自然水滴实际屏幕贡献连续性、遮挡、跨 chart、全材质与长期水痕艺术效果；预算内运行或像素有变化不等于自然、不卡顿和无闪烁。
- 长期运行、开关组合及内存/RID 总量泄漏检查仍待收口。BO/BP/BQ 已通过的具体生命周期切片不重复开发。

## 3. 完整 Release 与桌面验收

- 重跑加入 BS 后的 **29 阶段**完整 suite；最近实际整套仍是 BR 的 **28 阶段**。BT 尚未接入 suite 或执行新 PCK 专项。
- 构建实际完整 Release 包，核对生产输入、引擎与产物身份，并对全部桌面控件执行真实端到端操作及整体视觉复核。现有 Debug `.62`、PCK 专项、小型 Release 接触夹具均不能替代。
- 实际语音听感、长期表现和跨设备视觉仍需对应证据，不将 Dummy 音频输出当听感通过。

## 本轮验证边界与后续顺序

本轮只完成代码/调用点及既有验收记录审计与清单整理，没有生产修复、Godot 重跑或新包。因此三组仍全部开放。

下一步先实现第 1 组漫画 token 几何查询的最小接口及回归，再处理表情/暂停跨模块入口；BT 保留现场捕获路线；最后合并完整 suite、Release 与桌面验收。P06 的第二个标准角色、空白宿主复制和外部 AI 实际复核单独执行，不计入 P05 数量。
