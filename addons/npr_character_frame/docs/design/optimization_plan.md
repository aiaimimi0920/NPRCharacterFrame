# 开发优化计划

## 目标

交付可整目录复制的 Godot NPR 角色插件。所有既有功能均属框架范围，展示场景完整保留。按本项目模型标准提供的角色及配置可被加载；不适配任意模型，不开发导入向导，不修改引擎，不在插件内调用 AI。

## 阶段与验收

1. **P01 工作约定和文档组织（完成）**：根 AGENTS.md 固化不可遗漏的规则；三个独立文档目录分别承载 API、开发规划、模型制作提示词。文档链接已检查。
2. **P02 文件归属与路径（完成）**：持久测试已移入 `.ci_script/framework/`；测试模型资源已归入 `samples/silver_wolf/`；原 role 内容归入通用材质和 shader 目录。资源引用、UID 和入口同步，33 张渲染图与整理前一致。
3. **P03 构建与临时产物（完成，Windows 基线）**：默认测试输出 `.temp/`；引擎路径由参数/环境变量输入。四位编号、失败占号、版本重置已有测试；实际构建包 `1.3.0.2` 导出和启动通过，包含配套 DLL 与输入身份。新构建自动清理其 staging。
4. **P04 模型测试协议基线（完成基线）**：实际定义/几何校验、六视图、合规/建议/未评估协议和外部 AI 证据包已实现并验证；未调用 AI。柔和目标暂只提供数据与人工/外部 AI 复核，未实现校准后的自动审美评分。
5. **P05 全功能角色数据标准与框架解耦（进行中）**：详细切片已推进至 P05-BS（真实雨水调度/残留基线源码与 .62 PCK 各 291/291；最近实际整套仍是 BR 的 28 阶段，长期水痕视觉与完整 Release 仍待验证），眼动/表情、动作/口型、软组织、头发接触、装备、丝袜、湿润/雨水及多个离线生成入口已有角色输入和运行时归属；最新实现展示角色输入、方案身份和可选演示语音，默认银狼存档保持兼容，当前 Debug 包为 `1.3.0.62`。衣装严格区域门禁、固定步模拟与非悬停输入合同已通过双分辨率重复采集，本机综合采集的跨运行一致性与精确恢复已验证，实时序列和完整 Release 尚未整体关闭。仍须完成剩余展示业务接口审计、通用校准和整体视觉/Release 门禁。逐模块提取 sample 特定坐标/掩码/骨骼绑定为标准角色数据，消除不合理的样例与 UI 私有成员依赖；有意规定的 canonical 骨序和模型合同不是任意模型适配。不能只移动文件后宣称通用化完成。
6. **P06 新标准角色的完整验收（待实施）**：空白宿主复制插件 → 加载按规范提供的新角色与配置 → 全功能展示 → 无需 AI 检查 → 外部 AI 按测试协议给出建议 → 带四位版本包运行。P05 完成后执行；示例模型验证不能替代第二个标准角色验收。

本轮先实现 P01–P04 的基础设施和现有模型验收；P05–P06 的通用化需要后续独立开发，不以本轮目录迁移冒充完成。

实施结果和遗留范围见 [本轮记录](implementation_status.md)。
