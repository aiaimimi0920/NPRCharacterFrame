## 交付内容与启动

- **框架源码**：复制整个 [`addons/npr_character_frame/`](../../) 到自己的宿主项目，保持固定插件安装名，不只复制展示脚本。模型和配置遵循 [制作规范](../model_authoring/README.md)，使用用户提供的匹配引擎；不支持任意模型自动适配。
- **Windows 展示包**：宿主项目 [`.export/1.3.0.63/`](../../../../.export/1.3.0.63/)；`NPRShowcase.exe`、`NPRShowcase.pck`、`SpoutLibrary.dll` 必须保持在同一目录。直接运行 `NPRShowcase.exe`，无需给 EXE 传源码项目路径。随包 `build.json` 和 `source-inputs.json` 记录模式与身份。
- **编辑器使用**：启用插件后安装 shader globals，工具菜单 `Run NPR Character Showcase` 打开 [完整展示场景](../../showcase/wardrobe.tscn)。独立角色接入见 [开发者入口](README.md) 和 [展示角色输入](showcase.md)。
- **数据安全**：真实使用的方案写入 `user://`。既有自动化使用独立 APPDATA，未操作用户方案；人工检查“重置并保存”前请备份自己的方案，不把验收操作覆盖到已有创作上。

## 已知限制与未评估项

**BT（用户接受，不再阻塞交付）**：历史 1152×720 图像出现约 68–73 个像素的 RGB 一级差异，Alpha 不变；正常观看影响和根因仍未定。多次有界诊断未取得同一异常帧的完整 GPU 中间态，不将“未复现”写成修复。原严格失败、原图和诊断证据保留。正常自然水滴部分时刻的可见性与插值证据，不等于所有帧、所有材质无闪烁保证。

**现场听感（待接收处置）**：系统输出链路已验证；用户可确认实际播放和停止正常，或明确将听感移交接收后人工复核。没有证据表明存在新的音频程序缺陷，不据此追加无限测试。

2026-10-02 已提供一次实际 `.63` WASAPI 现场试听：首次播放等待自然结束，第二次在片尾前操作“停止语音”；使用独立 APPDATA，不录音、不调整系统音量、不执行保存或重置。包前后身份一致，进程正常退出且日志无错误/警告。该轮状态为 `interaction_completed_awaiting_user_feedback`，仍待用户确认实际听到的情况；不把成功点击、画面变化或未收到反馈当成听感通过，也不在没有反馈时反复自动试听。证据目录 `rolenpr2_p05_listening_20261002/`。

**范围外**：第二标准角色、跨设备性能、全新宿主的完整 P06 流程、外部 AI 审美评价未完成；不冒充本轮验收通过。

## 接收时的简短操作

1. 从上述 `.63` 目录启动 EXE，确认银狼角色、舞台和九个分类页可见；目标是模型完整呈现、控件可操作，而非只出现空窗口。
2. 在服装/丝袜/头发页做一个代表调整并恢复，确认对应外观改变；需要测试保存时使用备份或隔离方案。
3. 在湿润雨水页启用雨水，检查暂停/继续与重播控件；留意明显异常并按实际观察报告，不据此抹除 BT 历史像素差异。
4. 在面部表情页启动演示语音，确认现场能听见，点击停止后声音停止；此步骤用于补充尚未确认的物理听感。
5. 若要关闭 P05 接收回执，反馈第 4 步结果，或明确同意把现场听感移交接收后人工复核；无需重新出相同源码的包。
