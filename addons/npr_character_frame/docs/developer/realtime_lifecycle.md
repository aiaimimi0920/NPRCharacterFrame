# 实时生命周期验证边界

P05-BO 第一切片使用 `realtime_lifecycle_regression.gd` 实例化真实 `showcase/wardrobe.tscn`，保持动作驱动 `automatic=true`、动作与雨水 `_process` 开启。不绑定 CaptureClock，不手工向模拟函数喂固定 delta。每轮重新创建、运行、重置和释放场景，共三轮。

## 已覆盖合同

- 动作、动态头发、头发接触、雨水和漫画同时运行；动作时钟增长、真实雨滴出生、头发点继续变化且保持有限。
- 用真实雨水 Button 的 toggled/pressed 信号执行暂停、继续和从头播放。不是操作系统鼠标端到端测试。
- 独立暂停雨水后，水滴记录、积水、时钟和随机序列保持；角色动作和头发继续运行。切换功能页再回来，暂停按钮状态保持。
- A/B 锁定冻结动作调色板、头发点、雨水状态、漫画时钟和镜头。解除锁定恢复先前状态，不意外解除单独雨水暂停，也不解除原有全局动作/雨水暂停。
- 雨水重播立即清空旧水滴与时钟，之后由引擎自动演化；漫画按真实时间到期移除；切换四种动作后头发保持有限。
- 锁定时重置方案释放临时暂停、关闭动态头发、清空漫画/雨滴/水痕，保存字节恢复工厂方案，默认动作继续自动运行。
- `queue_free()` 后实例弱引用失效，`RenderingServer.frame_pre_draw` 连接数回到场景创建前基线；重复三轮不累计该类回调。
- 每帧记录雨水工作预算，更新数量不得超过当前预算。此项不是“达到某帧率”的性能承诺。

## 证据与运行

专项通过既有 `run_validation.ps1 -Mode capture -TestScript res://addons/npr_character_frame/.ci_script/framework/realtime_lifecycle_regression.gd` 执行，显式指定本项目引擎和新的输出目录。已加入 suite；suite 总阶段数现在是 26。BO 只运行本专项及限帧重复，不把 BN 的 25 阶段结果冒充新的 26 阶段整套验收。

输出 `realtime_lifecycle.json` 含逐项 checks，以及每帧 cycle、phase、wall_usec、动作时钟、雨水统计、头发有限性、automatic/processing 和漫画数量。每轮 216 个采样点、两张运行/锁定截图。真实 delta 与随机眨眼的取样时刻不同，因此不要求不同运行的 PNG 或模拟结果逐字节相同；暂停区间的冻结和重置存档字节仍按精确值检查，不放宽。

专项默认不人为限帧；本机补充了显式 30/15 FPS 上限的相同测试。FPS 上限是测试调度条件，不是测得的最低性能保障。逐帧 wall_usec 可用于核实实际间隔，但初始化、截图、切页和重绑定开销必须与稳定阶段分开分析。

## P05-BQ：actor 隐藏与重显示

`visibility_lifecycle_regression.gd` 使用真实引擎帧调度，分别直接隐藏 actor 和隐藏其 Node3D 父节点。每轮开启动作、头发/接触、压力形变、拟合丝袜、雨水、符号眼嘴和漫画，再执行锁定隐藏/重显示、运行中隐藏、手动暂停、隐藏时重置和场景释放。`visibility_lifecycle.json` 保存逐帧时钟、预算、有限坐标和节点可见性观察；GPU 截图来自真实展示 viewport。

### 模块时间与暂停合同

- **动作暂停查询只表示显式状态。** 动作驱动 `is_paused() -> bool` 返回最近 `set_paused()` 设置的实例状态，初始及 `reset_simulation()` 后为 false；读取不求值、不推进时间、不发信号。它不是“这一帧是否实际执行”的综合判断，不合并 `automatic=false`、`set_process(false)`、SceneTree 暂停或 actor/父节点隐藏。A/B 锁定前用此查询保存状态，锁定期间为 true，解锁恢复原值；重复锁定不覆盖原始快照。暂停仍允许显式 `evaluate_expression()`，不等于所有模块全部停止。

- **显式动作暂停优先于可见性。** `set_paused(true)` 后，自动 `_process()` 和显式 `apply_pose()` 都不因 actor 或其父节点隐藏而重置头发、改写动作调色板/压力形变。A/B 锁定沿用该暂停入口，重新显示保持锁定前的状态与 GPU RGBA；显示本身不解除暂停。
- **未暂停时保留现有隐藏策略。** 隐藏冻结动作/眨眼时钟和动作驱动的临时表情时长，并将头发、弹簧和压力形变中性化；显示后按最新设置重新求值、重建动态头发，不补算隐藏期间的模拟时间。它不是运行中隐藏前后动态画面完全相同的承诺。
- **隐藏不是全局暂停。** 雨水继续遵守其独立启用/暂停开关与单帧工作预算；漫画继续自己的寿命，过期后不会在显示时复活。A/B 才会同时冻结动作、雨水和漫画；取消/重置仍须显式执行。语音所有权仍按 BP 的播放代次，不由此新增隐藏时静音规则。
- 主展示世界里的 Body、Face、Hair、拟合层、符号曲面和漫画都应继承隐藏。独立 World3D 的深度/辅助代理可在对应 SubViewport 停用时保留旧 visible 标志；专项同时检查该 viewport 为 UPDATE_DISABLED，而不是把这些非绘制代理当作主画面残影。实际 GPU 隐藏图仍保留。
- 隐藏时重置不擅自显示 actor，解除临时暂停、清除雨水/漫画/表情；随后显示恢复工厂动作。隐藏/显示不写入方案，重置保存字节仍等于工厂方案。释放后弱引用与 frame_pre_draw 回调数量必须回到基线。

专项按暂停前后完整模拟字节和 GPU RGBA 零差异判定，不使用像素容差。跨运行的真实动作取样可以不同；不要求两次不同时间线的参考图相同。新增门禁使后续 suite 为 28 阶段；专项通过不等于重跑整套，也不覆盖长时间水痕轨迹、所有功能开关组合、全部桌面控件、完整 Release 或 P06 第二标准角色。
