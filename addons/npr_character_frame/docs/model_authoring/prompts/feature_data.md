# 全功能数据交付提示词（标准化期间）

你负责按 NPR Character Frame 的标准制作角色功能数据。先列出目标功能：表情/口型/眨眼/符号表情、头发动态与碰撞、装备、丝袜薄纱、湿润雨水、软组织及相关效果。对每项列出几何、骨骼或 blend shape、贴图、参数和绑定关系的交付需求。

当前完整样例数据位于 samples/silver_wolf；其中专用坐标、索引、图表和二进制数据不等同于通用合同。在正式功能合同发布前，不能宣称复制这份数据就能支持新模型。按照已明确的基础合同完成可验证部分，其余以“待标准化/待确认”清单提交，不自行创造框架尚未实现的字段。

每次交付包含可执行程序检查的结果、外部 AI 视觉建议、未覆盖项。只根据已确认接口制作配置，不修改插件来容忍违规数据。

漫画效果按 [漫画校准标准](../comic.md) 交付本角色 comic profile：标准动作骨名、actor 静止锚点、三卡片的有序偏移/尺寸及贴脸泪滴/排线双侧区域。不要抄用样例位置；提供固定条件开/关、head 动作、出生后绕转与真实头发遮挡对照。程序检查与外部 AI 复核共用 [漫画用例](../tests/comic_review.md) 的证据，缺少的寿命、背面或第二实例证据标记未评估。
