# 装备程序检查与外部 AI 复核

测试 ID：`model.equipment`。合同见 [装备数据](../equipment.md)。

无需 AI：通过 `.ci_script/model/check_model.gd` 检查待测角色定义，检查四槽位元数据、几何数组/索引/数值/色块、动作骨骼存在性以及材质场景的节点和材质约定。配置缺失时仅表示基础渲染，不应报告装备功能通过。框架专项 `equipment_profile_regression.gd` 验证替代几何、色块、骨骼、场景、分组、实际统计和湿润隔离。

在待测角色上逐槽采集关闭、合并几何、独立材质模式，再采集四槽同时开启、转头/抬手/转身、侧后视及湿润前后画面。保留 profile、几何、场景和贴图身份及程序报告，临时证据写宿主 `.temp/`。样例的 `equipment_material_lookdev.gd` 验证模式互斥、槽位可见性、姿态和材质响应，不能替代待测角色的截图。

样例可按 [装备烘焙](../equipment_baking.md) 附保存后 receipt、输入/产物身份及重建报告，复用已验证的十九网格、四槽 bridge、全部 UV/变换/材质、八张作者 PNG 与 GLB 完整 JSON/BIN 对照。区分作者粗糙度图与 glTF 打包纹理、八张制作图与六张实际绑定图；程序重建一致不代表待测角色的附件语义或视觉质量通过。

外部 AI 提示词：结合程序报告，检查两种材质路径的装备位置和轮廓是否一致、槽位是否属于正确骨骼、动作中是否漂浮或穿插、色块采样与湿润是否影响正确部位。分别给出数据合规错误和视觉优化建议，引用视角/帧并指出应修改几何、绑定、UV 还是材质。证据不足写未评估；只输出建议，不修改模型。允许直接复用已有程序测量与截图，不要求重新分析原始全量几何。
