# 诊断眼程序检查与外部 AI 复核

测试 ID：`model.eye_geometry`，数据合同见 [诊断眼资产](../eye_geometry.md)。

无需 AI：按 [测试说明](../../developer/testing.md) 运行 `.ci_script/model/check_model.gd`，传入角色定义和 `.temp/` 输出目录。程序检查已配置场景的根变换、节点名、单 surface、源材质类型、有限中心坐标、光学数值范围和 65 列均匀眼睑采样。未配置 profile 表示仅基础渲染范围，光学与闭合质量不作通过结论。

外部采集：在完整角色配置上记录诊断眼开/关、左右独立注视、不同瞳孔尺度、半闭/全闭、眼部湿润的固定视角截图与连续帧，附 profile、模型和 lid 数据身份以及控制参数。需要时补充原始眼表示的对照图。

外部 AI 提示词：

> 复用程序报告和参数记录，检查左右眼中心是否对齐、瞳孔是否异常漂移、眼皮闭合是否露缝或穿插、泪膜与眼白是否错误遮挡。记录 profile 的注视增益、层深、闭合曲面和泪膜参数，区分模型/标记、profile 校准与动态湿润状态的修改建议。将结构错误与视觉改进建议分开，引用具体视角和帧。资料不足时写未评估，只输出建议，不改模型。

框架不调用 AI 服务，AI 建议由外部模型制作流程消费。

当前样例可附 [眼表烘焙](../eye_baking.md) 的输入/产物身份和保存后 receipt，复用八眼表、完整 GLB/材质/嵌入纹理和左右标记的核验结果。旧独立 lid() 未参与生成，共享眼皮由 face-motion 数据提供；不要把眼表静态重建成功当作眼皮闭合或动态注视验收。
