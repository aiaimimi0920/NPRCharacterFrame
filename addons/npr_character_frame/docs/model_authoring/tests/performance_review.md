# 动作与口型的程序检查和外部 AI 复核

测试 ID：`model.performance` / `model.rig_layout`。输入为角色定义及其 `performance_data_path`、`rig_layout_data_path`，标准见 [动作数据](../performance.md)。

无需 AI：使用 `.ci_script/model/check_model.gd`，按 [运行说明](../../developer/testing.md) 提供 `--definition` 和 `.temp/` 下的 `--output`。程序检查骨骼顺序、动作帧、权重归一化、面部 delta 与原始网格顶点数；配置诊断端点时还检查 schema、标准骨序、父级有序无环、有限坐标与非零骨段。错误列入 `compliance_errors`；未提供可选数据只代表基础渲染范围，不代表通过动作或完整展示验收。

视觉证据：由外部测试程序或使用方在模型支持的动作场景采集四个动作的首尾及中间姿态、五个口型、左右独立眨眼和组合表情，另附同姿态 render/white/skeleton 对照与诊断端点身份。固定相机、灯光与时间，附输入数据身份、动作名、帧时间、口型权重及上述程序报告。程序结果可直接供 AI 复用，不需重新数顶点或计算权重。

外部 AI 提示词：

> 阅读程序合规报告及带时间和权重标记的截图/序列。检查关节扭曲、蒙皮拉伸、动作循环接缝、嘴唇穿插、口型辨识和眨眼闭合；对照同姿态骨骼图，检查诊断端点是否贴合本角色且随动画移动，不把平坦蒙皮矩阵原点当作作者骨段。将数据合规错误与视觉优化建议分开；引用证据文件及对应帧，说明建议修改的部位和预期效果。证据不足时写明未评估，不虚构通过或分数。只输出建议，不修改模型。

单帧截图不足以判断时序平滑性。框架不调用 AI，也不将外部 AI 建议当作确定性回归门禁。

对当前样例重建，另附 [烘焙工具](../performance_baking.md) 的保存后 receipt 和输入/产物身份，复用三部件权重、12 形状及四动作全帧对照结果。保存数据与 bridge 一致不代表关节形变、口型可读性或循环接缝已获视觉验收。
