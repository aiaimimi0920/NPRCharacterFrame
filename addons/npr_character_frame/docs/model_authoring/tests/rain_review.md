# 持续雨水程序检查与外部 AI 复核

测试 ID：`model.rain`，制作合同见 [雨水数据](../rain.md)。

无需 AI：运行 `.ci_script/model/check_model.gd`，已配置 rain profile 时校验 JSON 与文件尺寸，错误归为合规错误；未配置只表示基础渲染，不报告雨水功能通过。框架 `rain_profile_regression.gd` 覆盖非法输入、截断二进制、定义传播和替代三文件进入真实模拟/GPU 绑定。`surface_rain_regression.gd` 对当前样例检查实际 Body 顶点前缀、720 帧降雨、跨边、沉积、暂停、停止输入残留及重启；`analyze_surface_rain.py` 检查多灯光截图。`rain_continuity_regression.gd` 提供轨迹连续性与每帧预算证据。新模型需使用自己的近景锚点；样例回归锚点不能冒充新模型验收。

外部 AI：复用程序报告、三文件身份、atlas/材质分区可视化和固定相机连续帧。检查水滴是否贴合表面、是否沿重力流动、跨 chart 是否跳跃、织物与非吸水表面是否有合理差异，并检查暂停与恢复、停止降雨后的水迹。结合顶点偏差、流动计数和更新预算定位建议到几何、邻接、UV、chart 或材质分类。只输出优化建议；缺少连续帧或真实模型对应证据时标为未评估，不据单张截图给出连续性通过结论。框架不调用 AI，不自动修改模型。

显式运行时控制由 `rain_profile_regression.gd` 在不创建 showcase 的角色上验证：开启/关闭 shader、真实降雨、零输入保留水迹、种子切换清空及恢复重现、湿润参数改变吸收。测试使用实际样例的金属三角形，不将其结果推断为所有新模型材质均已验收。

近景锚点保存在 `.ci_script/framework/fixtures/silver_wolf_rain_anchors.json`，仅保留样例 Body 的两组三角索引、重心坐标和法线偏移；`rain_capture_anchors.gd` 从实际变形表面采样，替代旧生产附件加载。锚点属于回归 fixture，不属于正式角色资源，也不会进入构建包。

真实调度补充：`rain_realtime_regression.gd` 不手动推进模拟，在固定姿态下记录自然降雨、零输入后的自然退场、无活水滴时的材质残留、真实时间衰减及暂停/重启。相机须在首次骨骼同步后取锚点；恢复的相机/锚点/姿态与全画面 RGBA 都精确比较。GPU 清空检查扫描全部 texel，附单个微弱 texel 负对照。具体语义与边界见 [运行时基线](../../developer/rain_runtime.md#真实调度与残留基线)。

本机银狼两组近景及 `.62` PCK 已用于该基线，但水痕视觉较弱，不以“存在像素差”冒充足够清楚的艺术效果。两段各 60 帧自然序列须结合真实时间戳复核，不按固定 60 FPS 回放冒充原始速度；原始 CPU 轨迹不等于可见 GPU 水滴质心，遮挡或退场要单独识别。全动作、全材质、长时间运行、跨设备和第二角色仍需各自的真实证据。框架没有调用外部 AI，也未替外部 AI 给出评分。
