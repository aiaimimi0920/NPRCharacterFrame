# appearance.face_softness：无需 AI 路径

使用 capture_views.gd 生成六角度截图、固定相机参数、结构校验和测量数据。无需 AI 的用户可以直接检查 report.json 的合规错误，并手动观察这些图片。

可选运行 prepare_review.py 获取整体亮度均值/标准差与边缘响应均值，它不调用 AI。该指标覆盖整张图片，受头发、阴影、背景和曝光影响，不能冒充面部曲率或通用柔和度评分。没有经确认的面部区域、目标参考和阈值时，将“柔和是否达标”标为未评估，不自动给分。

人工对照六角度检查脸颊、下颌、鼻唇轮廓及明暗过渡；记录目标差距和建议。后续建立同相机/光照/遮挡条件的参考与面部区域后，再把适用的可重复测量规则加入此用例。
