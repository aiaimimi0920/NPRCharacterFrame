# 符号表情的程序检查和外部 AI 复核

测试 ID：`model.symbol_surfaces`，输入见 [符号曲面标准](../symbol_surfaces.md)。

无需 AI：按 [测试说明](../../developer/testing.md) 执行 `.ci_script/model/check_model.gd`，给定角色定义和 `.temp/` 输出目录。非空 profile 的中心、尺度、半径和有限数值由生产校验器检查。未配置 profile 只表示基础渲染范围；几何覆盖、符号贴合和遮挡列为未评估。

外部采集：使用完整配置的模型，固定光照与镜头，提供眼/嘴符号分别开启、同时开启、关闭恢复、尺寸与描边变化、正面及侧面/转头图像；记录实际模式、权重、角色参数及截图身份。附说话和眨眼输入在符号覆盖前后的记录，供检查临时接管和恢复。

外部 AI 提示词：

> 复用程序合规结果和参数记录，检查眼/嘴替换表面是否覆盖原洞口，墨迹是否居中、是否有原描边残留、侧视轮廓是否突起，以及关闭后原表情是否正确恢复。将参数合规错误与视觉优化建议分别输出，引用具体帧、部位和建议修改的 profile 字段。不能判断的项明确标为未评估。只输出建议，不改模型。

AI 由外部程序调用，框架不调用服务；参数通过不代表最终作者闭合曲面质量已经验收。
