# appearance.face_softness：外部 AI 提示词

目标：评估本角色面部是否具有用户要求的柔和表现，并只提出修改建议。

输入：六角度 PNG、相机/模型数据、程序合规错误和图像统计摘要。先核对角度完整性、面部是否清晰可见以及光照/发丝遮挡是否足以评价；背面不显示面部时不要臆造面部特征。程序给出的亮度、边缘均值仅是全图统计，不能单凭它们判断面部柔和，也不能当作曲率。

观察脸颊、下颌、鼻唇轮廓和明暗过渡。区分几何形状、法线、贴图、shader 参数、光照和相机造成的现象。复用已有数据，避免重新描述整套模型；证据不足时明确未评估，不强行给分。

输出 JSON：compliance_errors、visual_suggestions、not_evaluated。每条建议包含涉及的视角图片和区域、具体观察、可能原因、修改方向、复核方法及不确定性。仅把有明确标准与证据的违反项列为 compliance_errors；柔和偏好列为 visual_suggestions。不得修改模型或声称已经执行修改。
