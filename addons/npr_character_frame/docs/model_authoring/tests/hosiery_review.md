# 拟合丝袜程序检查与外部 AI 复核

测试 ID：`model.hosiery`。合同见 [丝袜纹理](../hosiery.md)。

无需 AI：运行 `.ci_script/model/check_model.gd` 检查待测定义；已配置 hosiery_profile 时检查六张纹理及非零尺寸，以及域边界有限性、高度递增和正半宽，错误归类为合规错误。未配置表示基础渲染范围，不可据此报告丝袜功能通过。框架回归 `hosiery_profile_regression.gd` 检查替代纹理进入真实 shell、实例材质隔离、Body 重建绑定、替代区域的严格边界和静止空间变换；`hosiery_surface_regression.gd` 和 `analyze_hosiery_surface.py <输出目录>` 为样例提供旋转、alpha/遮挡和错误状态负例验证。

配置了 `normal_correction_path` 时，程序还检查 schema、顶点数、有限数值、唯一合法索引和非零法线，模型检查进一步比对原始 Body 被记录顶点的位置；失败作为合规错误，不能据此宣称全部三角拓扑一致。框架专项覆盖非法输入、拒绝时不修改法线、替代 JSON 进入实际 Body、源资源不变；留空路径合法。

待测角色的视觉证据：在其完整展示场景固定相机与光照，采集每 30 度旋转的关闭层、开启层及透明度为零对照，补充弯腿/转身、袜口高度和缝线强度变化。提供 profile/纹理/法线修正 JSON 身份、导入色彩说明、控制参数及已有程序结果；法线修正需另给接缝近景和不同光照的前后对照。临时图像和测量保存在宿主 `.temp/`。样例回归不能替代待测角色的证据。

外部 AI 提示词：复用程序结果和截图，检查织纹比例与方向、粗糙度和法线的相位一致性、覆盖掩码边界、袜口、弯曲时贴合、背面透叠和关闭层后的残留。按图片/视角指出建议调整的纹理或模型域，并区分固定 shader 尺度造成的限制。区分合规错误与视觉建议；缺少证据时写未评估。只输出建议，不改模型，不把当前程序未测量的视觉质量写成通过。

框架不调用 AI 服务；外部程序可共用截图与程序摘要调用 AI，无需重复计算已有证据。

腿部 AO 校准：程序检查 UV 有限范围/顺序、高度递增及 G 下限；专项对照验证替代参数产生画面变化、关闭后参数变化不影响像素、恢复样例后精确还原。外部 AI 应使用固定光照的开关与区域近景，检查是否只是抬亮真实瑕疵、是否误抹阴影、掩码过渡是否自然；先确认问题位于当前 shader 支持的左侧候选域，不应把此功能当作通用 AO 自动修复。

服装掩码：专项验证缺失/空薄纱与缝线贴图被拒绝、替代三掩码绑定到实际 Body 材质，以及 Body 与拟合层共用 garment_mask。外部 AI 根据染色前后对照检查 RGB 权重是否串色、alpha 覆盖是否错位、R 通道薄纱/缝线是否与目标一致；metric seams 模式会替换贴图缝线结果，评价贴图缝线需明确关闭该模式。程序只检查资源与绑定，不根据尺寸判定通道内容正确。

织物尺度：程序拒绝非正/非有限纱线周期、非正重复次数及负/非有限壳偏移。实际渲染回归分别改变周期、重复次数和偏移，核对双材质绑定、像素变化及恢复。外部 AI 结合每 tile 重复次数、角色缩放和近景/远景，评价织纹是否过粗、是否混叠、壳是否浮起或穿插；程序不会从贴图自动判断真实烘焙重复次数，非均匀缩放的偏移误差不属于当前公式保证范围。

袜口配置：程序拒绝非有限或非正宽度、非有限或负偏移。框架表面回归分别改变三个参数，检查 Body/拟合层绑定、实际像素变化及恢复后的精确像素一致性。外部 AI 应结合参数和近景对照检查折边是否过宽、缝线是否落在预期带内、不同姿态下是否贴合；当前没有左右腿独立中心参数，不应建议修改已删除的 seam center/size uniform。
