# 软组织数据检查与外部 AI 复核

测试 ID：`model.soft_tissue`；标准见 [软组织数据](../soft_tissue.md)。

无需 AI：按照 [测试说明](../../developer/testing.md) 执行 `.ci_script/model/check_model.gd`，提供角色定义及 `.temp/` 下的输出目录。程序检查 JSON 字段、Body 顶点数量、索引唯一性和数值有限性。缺失可选配置表示仅检查基础渲染，不能算完成压力效果验收。结构错误写入 `compliance_errors`；形变质量和碰撞仍需证据。

样例制作还可运行 [烘焙与保存后验证](../soft_tissue_baking.md)，提供 Shape Key/bridge 误差、静止位置、UV、拓扑及权重归一化 receipt。该程序证据可以与下述截图共用，不能代替另一个角色的制作校准或动作碰撞测量。

采集由使用方或外部测试程序执行：固定相机和灯光，记录压力 0、0.5、1、恢复 0 的局部和全身图像、作用顶点列表、实际最大位移、域外顶点变化及可用的碰撞测量。附数据文件身份和模型尺寸。模型具备完整展示数据时，再采集装备切换、质量切换、隐藏恢复和动作组合。不可运行的流程明确标注未评估。

外部 AI 提示词：

> 阅读程序报告和压力序列。依据该模型声明的受压区域判断形变是否局部、平滑、自然，是否影响无关部位或出现可见穿插。复用现有顶点和位移测量，不重新猜测数值；区分结构合规错误与视觉优化建议。每条建议引用对应帧、部位和预期修改效果。截图不足以证明碰撞安全时写明未评估。只输出建议，不直接修改模型。

框架不调用 AI 服务。样例专项回归中的固定左腿 ROI、位移阈值和胶囊不作为其它模型的通用评分标准。
