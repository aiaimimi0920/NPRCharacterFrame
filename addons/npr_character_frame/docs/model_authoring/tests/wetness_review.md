# 湿润程序检查与外部 AI 复核

测试 ID：`model.wetness`，制作合同见 [湿润纹理](../wetness.md)。

无需 AI：运行 `.ci_script/model/check_model.gd`，检查已配置 profile 的四个资源、非零尺寸及有限 [0,1] 泪光 UV 上限；错误归为合规错误。无 profile 仅表示基础渲染范围，不能报告湿润功能通过。框架 `wetness_profile_regression.gd` 检查非法输入、定义传播、替代纹理与上限进入实际材质、强度保留和实例隔离；固定原绘制眼截图验证零上限关闭与干燥图一致、恢复源上限精确还原。此对照只证明样例的门控行为。现有 `visual_directions_regression.gd` 与 `surface_rain_regression.gd` 提供湿润/雨水行为证据，失败须如实保留。

外部 AI：复用程序报告、纹理身份和固定相机/光照截图，比较干燥、四区域独立湿润、全部湿润、睁眼/闭眼及雨水开关。判断吸收变暗和高光是否符合对应材质、区域是否串扰、眼泪是否成为覆盖脸部的光幕、头发双 pass 是否出现边缘不一致。给出定位到贴图通道或材质范围的修改建议；缺少证据写未评估，不把结构检查当作视觉评分。框架不调用 AI，不自动修改模型。
